# Проверка сайта — 12 октября 2026

Проверены статическая сборка и основные пользовательские сценарии локального сайта. Изменения не опубликованы.

## Исправления

- Основная библиотека поиска загружается при открытии поиска. Контроллер уменьшился примерно с 96 до 3 КБ несжатого JavaScript.
- Экранирование HTML вынесено в небольшой независимый модуль: просмотр фотографий больше не подтягивает парсер Markdown через общий модуль размером около 45 КБ.
- Комментарии загружаются при приближении к их блоку. Для блока зарезервировано место. Исправлена гонка между загрузкой виджета и переключением темы.
- Поиск получил явную подпись поля и возвращает фокус на вызвавшую его кнопку после Escape. Кнопка закрытия фотографий получила однозначное доступное имя.
- Шапка компактнее на экранах до 360 пикселей; подвал переносится без горизонтального переполнения.
- Усилен контраст цветных токенов кода в светлой теме: исправленные цвета дают от 5,29:1 до 6,54:1 на фоне #fafafa. Ориентир — [WCAG: минимальный контраст](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
- Недоступное sessionStorage больше не прерывает инициализацию режима автора.

## Проверки

- Сборка Astro: 146 страниц; индекс Pagefind: 147 страниц; 77 автоматических тестов прошли.
- Во всех 147 HTML-файлах проверены внутренние абсолютные ссылки, повторяющиеся id, наличие alt у изображений и доступного имени у кнопок. Ошибок в этих проверках не найдено.
- При ширине 320 пикселей проверены главная, обо мне, блог, мир, книги, игры и две записи. При ширине 1280 пикселей — главная, обо мне, мир и запись. Горизонтального переполнения и сломанных уже загруженных изображений не обнаружено.
- Клавиатура: переход к содержимому, поиск и Escape с возвратом фокуса, фотографии и стрелки с возвратом фокуса после закрытия.
- Карта: открытие и выбор Джаспера показывают информацию о городе. Обнаруженный сбой был вызван устаревшим кешем локального Vite после сборки; перезапуск восстановил загрузку.
- Комментарии не загружаются в начале длинной записи, загружаются при приближении к подвалу; переключение темы проверено.

## Границы проверки

Размеры JavaScript указаны без сжатия и не являются измерением времени загрузки. Lighthouse, реальные Core Web Vitals и работа на физическом телефоне не измерялись. Это локальная проверка отдельных критериев доступности, а не сертификация соответствия WCAG. Внешние сервисы карты и комментариев зависят от сети.
